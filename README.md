## 📖 نبذة عن المشروع

**مطعم الأندلس — Al Andalus Restaurant** هو مشروع موقع إلكتروني لمطعم مغربي تقليدي، يهدف إلى تقديم تجربة استخدام أنيقة وسهلة للزوار، بدءًا من استكشاف الأطباق المغربية والتعرف على المطعم، وصولًا إلى حجز الطاولات وطلب الطعام والتواصل مع المطعم.

يجمع الموقع بين الهوية المغربية الأصيلة والواجهات الحديثة، مع اعتماد اللون الأخضر المغربي والبيج والأبيض الكريمي، وإضافة الزخارف التقليدية والصور الاحترافية والمؤثرات الحركية.

تم توزيع العمل على خمسة أعضاء، بحيث يتولى كل عضو مجموعة محددة من صفحات الموقع.

## 🚀 طريقة تشغيل المشروع

1. انسخ رابط المستودع من GitHub.
2. نفّذ الأمر التالي في الطرفية:

```bash
git clone PUT_REPOSITORY_URL_HERE
```

3. انتقل إلى مجلد المشروع:

```bash
cd al-andalus-restaurant
```

4. افتح المشروع باستخدام Visual Studio Code.
5. شغّل `index.html` في المتصفح أو استخدم إضافة Live Server.
6. تحقق من تحميل الصور وملفات CSS وJavaScript بصورة صحيحة.
7. اختبر التصفح والحجز والسلة والنماذج والحركات.

تحتاج وظائف مثل المصادقة الحقيقية، وحفظ الحجوزات والطلبات، وإدارة البيانات إلى خادم أو خدمة مناسبة عند الاقتضاء.
