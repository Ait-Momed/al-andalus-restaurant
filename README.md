## 📖 عن المشروع | About the Project

**مطعم الأندلس — Al Andalus Restaurant** هو مشروع موقع إلكتروني لمطعم مغربي تقليدي، يهدف إلى تقديم تجربة رقمية متكاملة للزوار، بدءًا من التعرف على المطعم واستكشاف الأطباق، وصولًا إلى حجز الطاولات والشراء والتواصل مع المطعم.

يعتمد المشروع على تصميم عربي باتجاه RTL، وهوية بصرية مستوحاة من العمارة المغربية والزليج التقليدي، مع استخدام ألوان خضراء وبيج وكريمية وصور احترافية وحركات انتقالية أنيقة.

تم توزيع مهام التطوير على خمسة أعضاء، بحيث يتولى كل عضو مسؤولية صفحات ووظائف محددة من المشروع.

<a id="animations"></a>

## 🎞️ الأنيميشن وتجربة المستخدم | Animations & UX

يهدف المشروع إلى جعل تجربة الاستخدام أكثر أناقة وسلاسة، دون تغيير التصميم الأساسي أو المبالغة في الحركات.

- **Fade In:** ظهور تدريجي للعناوين والنصوص.
- **Scroll Reveal:** إظهار الأقسام عند وصول المستخدم إليها.
- **Hover Effects:** تفاعلات ناعمة عند مرور المؤشر على البطاقات.
- **Image Zoom:** تكبير خفيف للصور داخل الحاويات.
- **Button Transitions:** انتقالات سلسة للأزرار.
- **Form Feedback:** تأثيرات بسيطة لحقول الإدخال ورسائل التحقق.
- **Mobile Navigation:** حركات متناسقة لقائمة الهاتف.

تُراعى سرعة الصفحة وإمكانية الوصول وإعدادات `prefers-reduced-motion`، مع الحفاظ على الألوان والصور والأبعاد الأصلية.

## ⬇️ التثبيت والتشغيل | Installation & Usage

### تحميل المشروع

<p align="center">
  <a href="https://github.com/Ait-Momed/al-andalus-restaurant/archive/refs/heads/main.zip">
    <img src="https://img.shields.io/badge/Download-Project%20ZIP-145A38?style=for-the-badge&logo=github&logoColor=white" alt="تحميل مشروع مطعم الأندلس">

</p>

اضغط على زر التحميل للحصول على نسخة ZIP من المستودع على الفرع `main`، ثم فك ضغط الملف على جهازك.

### تشغيل المشروع محليًا

1. افتح مجلد المشروع باستخدام Visual Studio Code.
2. افتح ملف `index.html`.
3. استخدم Live Server لتشغيل الواجهة محليًا.
4. تحقق من تحميل الصور وملفات CSS وJavaScript.
5. اختبر الروابط والنماذج والأنيميشن على الهاتف والحاسوب.

### استنساخ المشروع باستخدام Git

```bash
git clone https://github.com/Ait-Momed/al-andalus-restaurant.git
cd al-andalus-restaurant
```

قد تتطلب المصادقة الحقيقية وإدارة الحجوزات والطلبات وجود خادم أو خدمة خارجية.
