## 📖 عن المشروع | About the Project

**مطعم الأندلس (Al Andalus Restaurant)** هو مشروع موقع إلكتروني احترافي لمطعم مغربي تقليدي، صُمّم ليجمع بين الأصالة المغربية والواجهات الرقمية الحديثة.

يهدف المشروع إلى توفير تجربة متكاملة للزوار، من خلال التعرف على المطعم واستكشاف الأطباق والمنتجات، وحجز الطاولات، والتواصل مع المطعم، وإدارة المشتريات. كما يتضمن واجهات مخصصة للمشرف لإدارة المطعم ومتابعة عملياته.

تم تطوير المشروع باستخدام HTML5 وCSS3 وJavaScript، مع اعتماد تصميم عربي باتجاه RTL، وألوان مستوحاة من الهوية المغربية، وصور احترافية، وحركات انتقالية أنيقة.

<a id="animations"></a>

## 🎞️ الأنيميشن وتجربة المستخدم | Animations & UX

يهدف الموقع إلى استخدام حركات احترافية تضيف الحيوية إلى الواجهات، مع الحفاظ على سرعة الأداء وسهولة التصفح.

### التأثيرات الحركية

- **Fade In:** ظهور تدريجي للعناوين والنصوص.
- **Scroll Reveal:** إظهار الأقسام عند وصول المستخدم إليها أثناء التمرير.
- **Hover Effects:** تأثيرات تفاعلية عند مرور المؤشر فوق البطاقات.
- **Image Zoom:** تكبير بسيط للصور داخل حاوياتها.
- **Button Transitions:** انتقالات ناعمة للأزرار.
- **Form Feedback:** عرض رسائل التحقق وحالات التحميل بسلاسة.
- **Mobile Menu:** انتقالات متناسقة لقائمة التنقل في الهاتف.

### معايير الجودة

- تجنب الحركات المبالغ فيها.
- الحفاظ على الألوان والأبعاد الأصلية للتصميم.
- احترام تفضيلات `prefers-reduced-motion`.
- تجنب الحركات التي تسبب اهتزاز العناصر أو بطء الموقع.
- اختبار الأنيميشن على الحاسوب والهاتف.
- ضمان بقاء النصوص والأزرار واضحة أثناء الحركة.

## 🚀 التثبيت والتشغيل | Installation & Usage

### 1. استنساخ المستودع

```bash
git clone PUT_REPOSITORY_URL_HERE
```

### 2. الدخول إلى مجلد المشروع

```bash
cd al-andalus-restaurant
```

### 3. فتح المشروع

افتح مجلد المشروع باستخدام Visual Studio Code، ثم افتح ملف `index.html` في المتصفح أو استخدم إضافة Live Server.

### 4. اختبار الصفحات

تحقق من النقاط التالية:

- تحميل الصور بصورة صحيحة.
- عمل روابط التنقل بين الأقسام.
- صحة عرض الموقع باللغة العربية واتجاه RTL.
- عمل أزرار الحجز والشراء.
- عمل نماذج الإدخال والتحقق من البيانات.
- تناسق التصميم على الهاتف والحاسوب.
- ظهور الأنيميشن بصورة ناعمة.

قد تتطلب وظائف تسجيل الدخول الحقيقية وحفظ الطلبات والحجوزات وجود خادم أو خدمة خارجية.

## 🔐 الأمان والخصوصية

يجب حماية بيانات المستخدمين والحجوزات والطلبات. لا تخزّن كلمات المرور أو مفاتيح API السرية في JavaScript المتاح للزوار.
