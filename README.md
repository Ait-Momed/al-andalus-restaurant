# 🍽️ مطعم الأندلس | Al Andalus Restaurant

موقع إلكتروني لمطعم مغربي تقليدي يجمع بين الأصالة المغربية والتصميم العصري، باستخدام **HTML5 وCSS3 وJavaScript**. يهدف المشروع إلى تقديم تجربة متناسقة للزوار، من خلال التعريف بالمطعم وعرض الأطباق وتسهيل الحجز والطلبات والتواصل، مع تجهيز واجهة خاصة بالمشرف.

> **تنبيه:** الصور المعروضة أدناه هي نماذج تصميمية للواجهات (UI mockups)، وليست دليلًا على أن جميع وظائف الموقع قد بُرمجت بالفعل.

## 📌 معلومات المشروع

- **اسم المشروع:** مطعم الأندلس — Al Andalus Restaurant
- **نوع المشروع:** موقع إلكتروني لمطعم مغربي
- **اللغة الأساسية:** العربية
- **اتجاه الواجهة:** من اليمين إلى اليسار (RTL)
- **الهوية البصرية:** مغربية تقليدية بلمسات عصرية
- **الألوان الأساسية:** الأخضر المغربي، والبيج، والأبيض الكريمي
- **تقنيات الواجهة:** HTML5 وCSS3 وJavaScript
- **رابط المستودع:** https://github.com/Ait-Momed/al-andalus-restaurant/tree/main

## 🎨 الهوية البصرية

يعتمد التصميم على الزخارف المغربية التقليدية، وصور المطعم والأطباق، والخطوط العربية الواضحة، مع حركات انتقالية خفيفة وتأثيرات تفاعلية. يجب الحفاظ على تناسق الألوان والمكوّنات في الصفحات المختلفة، مع مراعاة سهولة الاستخدام على الحاسوب والهاتف.

## 🖼️ معاينة التصاميم

### الصفحة الرئيسية — Home

أنجز العضو الأول تصميم الصفحة الرئيسية، بما في ذلك صورة المطعم كخلفية رئيسية، واسم المطعم، ورسالة الترحيب، وأزرار الحجز والطلب عبر واتساب.

![تصميم الصفحة الرئيسية لمطعم الأندلس](assets/images/home-page.png)

### نظام الحجز — Reservations

أنجز العضو الأول تصميم واجهة الحجز، التي تتضمن نموذجًا لإدخال تاريخ الحجز ووقته وعدد الأشخاص ونوع الطاولة ومعلومات التواصل، مع زر تأكيد الحجز عبر واتساب.

![تصميم واجهة حجز الطاولة](assets/images/reservation-page.png)

## 📄 صفحات الموقع ووظائفها

### 1. الصفحة الرئيسية — Home

- صورة احترافية للمطعم كخلفية رئيسية.
- اسم المطعم ورسالة ترحيبية.
- أزرار للانتقال إلى قائمة الطعام والحجز والطلب عبر واتساب.
- عرض مختصر لمميزات المطعم.
- تصميم متجاوب مع مختلف الشاشات.

### 2. من نحن — About Us

- نبذة عن المطعم وفكرته.
- صور المطعم والديكور والأطباق المغربية.
- عرض مميزات المطعم باستخدام بطاقات متناسقة.

### 3. قائمة الطعام — Menu

- عرض الأطباق مع الصور والأسماء والأسعار.
- تصنيف الأطباق حسب الفئات عند تنفيذ الوظيفة.
- بطاقات منتجات ذات تصميم موحّد.
- قابلية إضافة البحث والتصفية.

### 4. سلة الطلبات — Cart

- عرض الأطباق التي اختارها المستخدم.
- تعديل الكميات وحذف المنتجات.
- حساب المجموع.
- الانتقال إلى إتمام الطلب.

### 5. الحجز والطلبات — Reservations & Orders

- نموذج حجز طاولة يتضمن التاريخ والوقت وعدد الأشخاص ونوع الطاولة.
- جمع معلومات التواصل اللازمة من الزبون.
- إمكانية تجهيز رسالة تأكيد عبر WhatsApp.
- التحقق من الحقول وإظهار رسائل واضحة للمستخدم.

### 6. التواصل معنا — Contact Us

- معلومات الاتصال بالمطعم.
- العنوان وموقع المطعم.
- أوقات العمل.
- صورة لواجهة المطعم.
- روابط التواصل الاجتماعي.

### 7. تسجيل دخول المشرف — Admin Login

- واجهة دخول عربية ومتناسقة مع هوية المطعم.
- التحقق من الحقول المطلوبة.
- إمكانية إظهار كلمة المرور وإخفائها.
- ربط النموذج بخدمة مصادقة حقيقية قبل النشر.

### 8. لوحة التحكم — Admin Dashboard

- ملخص الطلبات والحجوزات.
- عرض الإحصائيات.
- إدارة المنتجات والأسعار.
- متابعة الطلبات والحجوزات.
- واجهة إدارية منظّمة.

> تنفيذ تسجيل الدخول الآمن وإدارة البيانات الحقيقية يحتاج إلى خادم أو خدمة مناسبة؛ الواجهة الأمامية وحدها لا تكفي للمصادقة الآمنة.

## 🚀 تشغيل المشروع محليًا

1. استنسخ المستودع إلى جهازك باستخدام Git، أو نزّل ملفات المشروع من GitHub.
2. افتح مجلد المشروع في Visual Studio Code.
3. افتح `index.html` في المتصفح، أو استخدم إضافة Live Server.
4. تأكد من صحة مسارات الصور وملفات CSS وJavaScript.
