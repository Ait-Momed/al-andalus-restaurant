<a id="about-project"></a>

## 📖 عن المشروع

**مطعم الأندلس — Al Andalus Restaurant** هو موقع إلكتروني لمطعم مغربي تقليدي، يجمع بين أصالة المطبخ المغربي وجمال التصميم الحديث.

يهدف المشروع إلى توفير تجربة استخدام سهلة وأنيقة، تتيح للزوار التعرف على المطعم واستكشاف الأطباق والمنتجات، وحجز الطاولات، وإتمام الطلبات، والتواصل مع المطعم.

يتضمن المشروع أيضًا واجهات إدارية لتسجيل دخول المشرف ومتابعة عمليات المطعم.

### تشغيل المشروع محليًا

بعد تحميل الملف وفك ضغطه:

1. افتح مجلد المشروع باستخدام Visual Studio Code.
2. افتح ملف `index.html`.
3. استخدم Live Server لتشغيل الواجهة محليًا.
4. اختبر الروابط والصور والأزرار والنماذج.
5. تحقق من التصميم على الحاسوب والهاتف.

يمكن أيضًا نسخ المشروع مباشرة باستخدام Git:

```bash
git clone https://github.com/Ait-Momed/al-andalus-restaurant.git
cd al-andalus-restaurant
```
