# 🍽️ مطعم الأندلس | Al Andalus Restaurant

موقع إلكتروني احترافي لمطعم مغربي تقليدي، يجمع بين أصالة المطبخ المغربي وأناقة التصميم العصري، باستخدام HTML5 وCSS3 وJavaScript.

يهدف المشروع إلى توفير تجربة استخدام متكاملة للزوار، تشمل استكشاف الأطباق المغربية، والتعرف على المطعم، وحجز الطاولات، وطلب الطعام، والتواصل مع المطعم، بالإضافة إلى واجهة لتسجيل دخول المشرف ولوحة لإدارة المطعم.

## ✨ الأنيميشن الاحترافي — Professional Animations

يهدف المشروع إلى استخدام حركات انتقالية أنيقة تضيف الحيوية إلى الواجهة، دون المبالغة في التأثيرات أو تغيير التصميم الأصلي.

### 1. ظهور العناصر تدريجيًا

- ظهور العناوين والنصوص عند تحميل الصفحة.
- انتقال البطاقات إلى مواضعها بسلاسة.
- ظهور أقسام الصفحة عند وصول المستخدم إليها أثناء التمرير.

### 2. أنيميشن البطاقات والصور

- ارتفاع بسيط للبطاقات عند مرور المؤشر.
- ظلال ناعمة عند التفاعل مع المنتجات.
- تكبير خفيف للصور داخل حاوياتها.
- انتقالات سلسة عند إضافة منتج إلى السلة.

### 3. أنيميشن الأزرار

- تغيير لوني تدريجي عند مرور المؤشر.
- حركة ضغط بسيطة عند النقر.
- ظهور حالات واضحة للأزرار أثناء التحميل.
- الحفاظ على تباين الألوان وسهولة القراءة.

### 4. أنيميشن القائمة والتنقل

- انتقالات ناعمة عند فتح وإغلاق قائمة الهاتف.
- حركة بسيطة عند الانتقال بين الأقسام.
- إبراز الروابط النشطة بصورة واضحة.
- الحفاظ على اتجاه RTL في جميع عناصر التنقل.

### 5. أنيميشن صفحة تسجيل الدخول

- ظهور بطاقة تسجيل الدخول بهدوء.
- تفاعلات ناعمة لحقول الإدخال.
- إظهار رسائل التحقق دون إرباك المستخدم.
- انتقالات متناسقة عند تبديل إظهار كلمة المرور.

### 6. معايير جودة الأنيميشن

- استخدام CSS Transitions وCSS Keyframes عند الحاجة.
- استخدام JavaScript و`IntersectionObserver` لتفعيل ظهور العناصر عند التمرير.
- تجنب الحركات الثقيلة التي تؤثر في الأداء.
- احترام إعدادات `prefers-reduced-motion`.
- تجنب تحريك عناصر كثيرة في وقت واحد.
- عدم تغيير الألوان أو أحجام العناصر أو توزيعها لمجرد إضافة الأنيميشن.
- الحفاظ على سهولة الاستخدام على الهاتف والحاسوب.

**ملاحظة:** هذا القسم يوثق الحركات المطلوبة في المشروع؛ يجب تنفيذها فعليًا في ملفات CSS وJavaScript والتحقق منها قبل اعتبارها مكتملة.

```bash

```

5. افتح المجلد في Visual Studio Code.
6. شغّل ملف `index.html` في المتصفح، أو استخدم إضافة Live Server.
7. تحقق من تحميل الصور بصورة صحيحة.

إذا كانت هناك حاجة إلى تسجيل دخول حقيقي أو تخزين بيانات العملاء أو معالجة الطلبات والحجوزات، فيجب توفير خادم أو خدمة مناسبة مع حماية بيانات المستخدمين.

لا تُخزّن كلمات المرور أو مفاتيح API السرية في ملفات JavaScript المتاحة للزوار.

يجب استخدام HTTPS عند نشر الموقع وتطبيق آليات مصادقة مناسبة قبل إتاحة لوحة التحكم.
